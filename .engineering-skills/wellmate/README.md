# WellMate Engineering Control Layer

This directory contains WellMate-specific engineering workflow rules.

These rules complement, and never override, the authoritative `CLAUDE.md`
at the repository root.

Priority order:

1. CLAUDE.md
2. WellMate architecture and locked-system rules
3. WellMate engineering control layer
4. General engineering skills
5. Task-specific instructions

The purpose of this layer is to turn natural-language development requests
into controlled, traceable engineering work while minimizing regressions.
